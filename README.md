# Xtreme Darkroom

Painel UXP para Photoshop 24.2+ — receitas não destrutivas, um undo, offline.

## Instalar no Windows

1. [Download ZIP](https://github.com/Xtremefottos/xtreme-darkroom/archive/refs/heads/main.zip)
2. Extrai. Dentro da pasta tem de existir `manifest.json`.
3. Creative Cloud → **UXP Developer Tools** → Enable Developer Mode.
4. Photoshop → Editar → Preferências → Plug-ins → Ativar modo do desenvolvedor.
5. UDT → **Add Plugin** → escolhe `manifest.json`.
6. **••• → Load**
7. Photoshop: Plug-ins → Painéis de plug-ins → **Xtreme Darkroom**

Se o painel já estava carregado: Unload, substitui a pasta, Load de novo.

## Teste

Abre um retrato → **Pele** → grupo `XT · Pele` nas camadas. Ctrl+Z desfaz num passo.
