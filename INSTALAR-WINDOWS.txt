Xtreme Darkroom — instalar e testar (Windows)
Photoshop 24.2 ou mais novo.

1. PREPARAR
- Creative Cloud atualizado, Photoshop 24.2+.
- Instalar "UXP Developer Tools" no Creative Cloud.
- Abrir o UDT e marcar Enable Developer Mode.
- Photoshop > Editar > Preferencias > Plug-ins > Ativar modo do desenvolvedor.

2. EXTRAIR
- Extraia este pacote para Documentos\xtreme-darkroom
- Tem que existir manifest.json nesta pasta.
- Nao carregue o arquivo .zip no UDT.

3. LOAD
- Photoshop aberto + UXP Developer Tool.
- Add Plugin > selecione manifest.json
- ... > Load
- Photoshop: Plug-ins > Paineis de plug-ins > Xtreme Darkroom
- Docke a direita.

4. TESTE
- Abra um retrato (JPG/PSD).
- Intensidade 50 > botao Pele.
- Camadas: grupo "XT · Pele". Sem flatten.
- Historico: um passo "Xtreme · …". Ctrl+Z remove o grupo.
- Perfil Casamento > Aplicar perfil inteiro.
- Varios grupos XT, um so passo no Historico. Ctrl+Z desfaz o perfil todo.

5. ATUALIZAR (se o painel ja estava instalado)
- UXP Developer Tool > ... > Unload
- Substitua a pasta xtreme-darkroom pela extraida deste zip
- ... > Load  (ou Reload)
- No Photoshop o catalogo tem de aparecer: Rápidos, Estudio, Pele, D&B, Olhos, Batom, Detalhes, Desfoque, Finalizacao, Salvamento.

- Load vermelho: escolheu o zip em vez do manifest.json.
- "Abra um documento": nao ha arquivo aberto.
- Painel sumiu: Plug-ins > Paineis de plug-ins.
- Load recusa: Developer Mode desmarcado. Marque e reabra o UDT.
